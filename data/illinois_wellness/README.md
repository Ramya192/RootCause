# Illinois Workplace Wellness data

| File | What it is |
|---|---|
| `firm_admin.csv` | The public-use file, unmodified: `data/csv/firm_admin.csv` from https://github.com/reifjulian/illinois-wellness-data (4,834 enrolled employees; `treat` was randomized: 3,300 treated, 1,534 control). CC0. |
| `wellness.csv` | Derived by `scripts/prepare_illinois_wellness.py`: an `employee_id` (row order), the assignment `treat`, the outcome `terminated_0119` and seven pre-assignment covariates. Everything measured after assignment is dropped on purpose. |
| `wellness_synthetic.csv` | A **fully synthetic** mirror with the same columns and roughly the same marginals, and a *planted* treatment effect. Generated by `scripts/generate_synthetic_wellness_data.py` from `illinois_wellness_scm` in `rootcause/evaluation/scms.py`. Not real data and not a claim about the real program. |

**Cite:** Jones, D., Molitor, D., & Reif, J. (2019). "What do Workplace Wellness Programs do? Evidence from the Illinois Workplace Wellness Study." *Quarterly Journal of Economics* 134(4).

**Terms:** the data's own terms forbid using it to investigate specific research subjects. The six public files cannot be linked to each other, so only `firm_admin.csv` is used.

The study's published finding is a null effect of the program on the outcomes used here, which is why it serves as a false-positive check for the pipeline.
